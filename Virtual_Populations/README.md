# Virtual Population Inference tutorial

## Andrew Matteson & Andrzej Kierzek, November 2025

### The model
Tutorial uses minimal model of Cancer Immunity Cycle with anti-PD1 treatment. The model is based on publication Lazarou G, Chelliah V, Small BG, Walker M, van der Graaf PH, Kierzek AM. Integration of Omics Data Sources to Inform Mechanistic Modeling of Immune-Oncology Therapies: A Tutorial for Clinical Pharmacologists. Clin Pharmacol Ther. 2020 Apr;107(4):858-870. doi: 10.1002/cpt.1786.  - here we use updated version of original model.

THE MODEL HAS BEEN QUALIFIED FOR TRAINING PURPOSES ONLY AND SHOULD NOT BE USED FOR DRUG DEVELOPMENT.

### Before running the project

Add matplotlib as a project dependency by clicking the "Edit Project Dependencies" link on the right. Use package name `matplotlib`, package type `PyPi`, and package version `==3.10.*`.

### How to start the tutorial?

Open notebook VPop_inference_v2.ipynb.
To open model in Design click on CIC_v4.2.0.iqd
